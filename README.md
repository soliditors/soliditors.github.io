# Soliditors

Site statique de la communauté Soliditors. HTML et CSS suffisent pour modifier et prévisualiser le site. Les images sont dans `assets/`.

## Prévisualisation locale

Depuis ce dossier, lancer `python3 -m http.server 8000 --bind 127.0.0.1`, puis ouvrir <http://127.0.0.1:8000>.

## Publication sur GitHub Pages

Le site est destiné à <https://soliditors.github.io/>. Les fichiers du site, dont `index.html` et `.nojekyll`, sont à placer à la racine de la branche `main` du dépôt `soliditors/soliditors.github.io`. Dans **Settings → Pages**, la source de publication est **Deploy from a branch**, **main**, **/ (root)**.

[Documentation GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)
